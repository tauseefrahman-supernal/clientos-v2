# Kickoff Checklist — Proving Value in Month 1

> **Phase:** Delivery Strategy · **Role:** Input
> **Answers:** What great onboarding looks like — how we kick off, aggressively gather what we need, hit the first time-to-value moment fast, and re-scope with real information.
> **Source:** GTM + Scoping 101 (kickoff checklist).
> **Framework:** `Frameworks/Client-Journey-Framework.md`

## 0. Before kickoff (handoff from scoping)
- [ ] Understand the full vision / objective / roadmap of the client
- [ ] Confirm high-level milestones / phases from the proposal (if none, break into milestones)
- [ ] Confirm the FDE on the project; onboard them. Pull engineering risk flags from the proposal review (integration unknowns, feasibility risks like scraping / voice)
- [ ] Confirm the time-to-value moment from the proposal: what we demo, to whom, by when (target: visible in week 1-2, value proven in month 1)
- [ ] Plan what to show the first weeks, before kickoff

## 1. Kickoff meeting (week 1)
- [ ] Kickoff presentation: re-anchor the 12-month vision, then focus on month 1
- [ ] Set the recurring weekly call; agree communication channel (Slack / email) and who responds on each side
- [ ] Walk through pilot-stage first-phase milestones
- [ ] Turn the proposal's systems table into an access checklist; request everything day 1, even for systems we touch late
- [ ] Set up Project OS with the first milestone

## 2. Show value fast (weeks 1-2)
- [ ] Build MVP-first: simplest viable version of the AI employee / solution, then layer complexity
- [ ] Show something in week 1-2: first prototype iteration, even simple (e.g. querying their knowledge base) to get feedback and build trust
- [ ] Ask questions to understand: the problem, the systems, priority / urgency

## 3. Scope with real information (weeks 3-4, months 2-6)
Proposal milestones beyond month 1 were our best guess.
- [ ] AI Strategy doc / roadmap draft → building
- [ ] Start scoping the next order form with what we have learned (real systems, real complexity, real priorities)
- [ ] Update the systems table with what we actually found
- [ ] Validate the proposal's problem is still the highest-value one; re-prioritise with the champion if not
- [ ] Confirm or adjust month 2-3 milestones with the client, framed as partnership ("we move as fast as you can"), not a scope change
